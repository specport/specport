# SpecPort GitHub Pages

This directory is a dependency-free static site. GitHub Pages publishes it
from the `main` branch through `.github/workflows/pages.yml`.

The page is the operational front door for the local-first CLI. It leads with
the current final-tree review-coverage wedge, a verified source install path,
real command/docs links, package metadata, release truth, privacy boundaries,
and explicitly labeled roadmap work. Its visual identity is distinctive, but
install and inspection actions take priority over editorial storytelling.

`release.json` is generated by `npm run site:sync` from `package.json` and a
fail-closed npm registry check. The Pages workflow regenerates it before upload.
`NOT-PUBLISHED` is the correct state until the exact package version and tarball
are returned by npm.

The current merge convergence command is `specport spec guard`: it consumes an
explicit receiver or approved scope plus identity-bound contract acceptance,
verification, taste, and candidate-lock evidence. A passing guard is
`merge-ready`, not a publication or ship approval.
