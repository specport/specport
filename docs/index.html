01 / The premise

A green test suite is not a ship decision.

AI-assisted changes often arrive after the session is gone, with a summary that sounds complete and a working tree nobody has bounded. SpecPort makes the final-state relation explicit without becoming another reviewer, recorder, or control plane.

05 / What is real today

A small tool with a serious boundary.

The receiver-first wedge is the current product. The contract layer now includes deterministic draft authoring, readiness checks, a bounded repository map, a provenance-preserving GitHub pull, and lineage-aware lifecycle handoffs, while staying honest about what still needs a human.

07 / The honest part

Not an AI reviewer.
Not a magic compiler.

SpecPort does not infer behavior from hashes, replace tests, or turn a generated paragraph into a ship decision. It makes the boundary between evidence, contract, taste, and authority visible enough for an existing review system to use.
