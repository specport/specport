06 / LOCAL BY DEFAULT

Evidence stays close to the project.

SpecPort inspects locally by default. It makes the network boundary explicit instead of hiding it behind a hosted account.

01No source upload

No source, prompts, transcripts, or credentials go to a SpecPort service.

02Explicit network

Only a requested receiver URL or one exact GitHub ref may be contacted.

03Human authority

Automation reports facts; people own intent, taste, and the final ship decision.

NON-GOALSNot an AI reviewer. Not a magic compiler. Not a hosted account.

07 / ROADMAP

A public index can come later.

Portable specs, exact discovery, cover/remix lineage, verified build evidence, and reputation are the direction. They become public surfaces after real specs are being pulled, covered, remixed, and built by external users.
